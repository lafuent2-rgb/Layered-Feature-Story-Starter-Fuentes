Complete one row for every positioned, layered, clipped, rounded, or shape-wrapped element. Duplicate rows as needed.

Element Content purpose Normal-flow baseline Chosen technique and why Containing block / stacking context Fallback or disengagement Required test
Issue badge Identifies the story as part of Phoenix heat response information. The badge remains readable as text inside the feature header. Absolute positioning anchors the badge to the top right of the header without affecting the main page layout. .feature-header is positioned relative and acts as the containing block. The badge does not create a separate z-index layer. If positioning is removed, the badge returns to normal flow inside the header. Test at 320px, 768px, 1280px, and 200% zoom for overlap or clipping.
Story guide Lets readers move quickly between the main sections of the story. The guide appears in normal document flow before the article content. Sticky positioning is used on wider screens so the navigation stays visible while the reader moves through the article. The story guide stays within the main grid and uses the sticky layer token. Below 52rem, sticky positioning is not applied and the guide remains in normal flow. Test scrolling at wide viewport sizes and confirm links remain keyboard accessible.
Pull quote Highlights the main idea that shade is part of Phoenix's heat response strategy. The quote remains a normal blockquote within the article. Relative positioning, z-index, and a small negative inline margin create a controlled overlap on wider screens. The pull quote stays inside the article and uses the raised layer token. Below 52rem, the negative margin and raised layer are not applied, so the quote returns to normal flow. Test at 320px, 768px, 1280px, and 200% zoom for collisions or horizontal scrolling.
Feature figure accent Adds a small sun like visual accent that supports the Phoenix heat theme. The figure and its content remain fully readable without the decorative accent. An absolutely positioned pseudo element is used because the accent is purely decorative and should not affect the figure's normal layout. .feature figure is positioned relative and acts as the containing block. The accent uses the raised layer token. If the pseudo element is unsupported or removed, the figure remains unchanged and readable. pointer-events:none prevents the decoration from blocking interaction. Test at 320px, 768px, 1280px, 200% zoom, and keyboard navigation to confirm the accent does not cover content or interfere with interaction.
Shape portrait Supports the heat relief section with a circular editorial image. The image remains in normal flow as a rounded image without shape wrapping. border-radius creates the circular image, while shape-outside is used on wider screens so surrounding text can wrap around the circle. The image remains inside the article section and does not require a separate stacking context. If shape-outside is unsupported, the circular image remains visible and the text continues in normal flow. Test at 320px, 768px, 1280px, and 200% zoom to confirm readable text wrapping and no content collisions.
Feature image clipping Gives the main story image a subtle editorial shape without hiding essential content. The image displays as a normal responsive rectangle when clipping is not applied. clip-path uses a subtle polygon shape to add visual interest while keeping the image easy to understand. The clipped image remains inside .feature-figure and does not create a new stacking context. The clip-path is inside an @supports rule. If unsupported, the image remains rectangular and fully readable. Test at 320px, 768px, 1280px, and 200% zoom to confirm the image is not cropped in a way that removes important information.
